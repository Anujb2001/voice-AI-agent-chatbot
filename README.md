# Speech Chat Agent

## Overview
Speech Chat Agent is a React application that enables users to interact with an AI agent using voice commands. The application utilizes speech recognition to capture user input and text-to-speech to provide responses from the agent.

## Features
- Real-time speech-to-text conversion
- AI agent response generation
- Text-to-speech for agent responses
- Clipboard copy functionality
- Continuous speech recognition

## Installation
### Prerequisites
- Node.js (>=14.x)
- npm or yarn

### Steps
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/speech-chat-agent.git
   cd speech-chat-agent
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm start
   ```

## Usage
- Click on **Start Listening** to begin speech recognition.
- Speak into the microphone, and your speech will be converted to text and displayed in the chatbox.
- The AI agent will generate a response and speak it out loud.
- Click **Stop Listening** to end the session.
- Copy any conversation text using the **Copy to clipboard** button.

## Technologies Used
